TaskFlow 设计规范 · v2.0 「静默」

一套为「记录摩擦」而设计的界面

TaskFlow 是面向个人的 AI 任务协作平台。本方案的目标是让技术用户在 10 秒内把想法变成可追踪的任务，同时让初次接触的人在 5 秒内看懂产品价值。平台策略为桌面端 Web 优先，平板与移动端 Web 作为降级适配。

桌面 1440×900 基准 深色优先 键盘平行 WCAG 2.1 AA Tailwind v4 令牌驱动
01

设计原则

五条原则按优先级排列。原则 P3「状态诚实」是本项目的强制约束——任何异步交互缺少五态中的任一态，视为设计未完成。

P1
内容优先
界面是任务的容器。删掉所有装饰，层级只靠留白与对比建立。
P2
键盘平行
鼠标能做的键盘都能做，且更快。拖拽必须有键盘替代路径。
P3
状态诚实
idle / loading / empty / error / success 五态全覆盖，绝不展示虚假成功。
P4
密度自选
同一套令牌支持紧凑与舒适两档密度，无需重写组件。
P5
深浅同源
浅色是深色的变量替换结果，不是第二套设计。

03

字体与间距

工具型产品以 14px 为正文基准而非 16px，用更小的字号换取信息密度。中文不得小于 12px，字重只用 400 / 500 / 600，避免浏览器伪粗体把笔画糊掉。

07

导航与操作路径

三层导航模型：全局层（侧边栏 + 命令面板）、上下文层（视图切换与筛选）、对象层（详情抽屉）。全部视图状态写入 URL，保证可分享、可后退、可刷新还原。

按键动作生效范围
⌘K / Ctrl+K打开命令面板全局
N / C新建任务，抽屉自动聚焦标题全局（非输入态）
/聚焦搜索框列表 / 看板
G → O / I / S跳转 概览 / 任务 / 设置（序列键）全局
B / L切换看板 / 列表视图任务页
⌘↑ / ⌘↓卡片移动到上一列 / 下一列看板（卡片聚焦时）
⌘Enter提交表单 / 确认创建抽屉、弹窗
Esc关闭当前层：抽屉 → 弹窗 → 清空搜索全局
输入框聚焦时禁用除 Esc 与 ⌘Enter 外的所有单键快捷键，避免打字触发跳转。移动端无拖拽，改为长按卡片弹出状态选择面板。

## 项目架构分析与文档产出

**背景**：`my-app`（包名 `helio-app`）实际是 TaskFlow 项目——Linear 风格的 AI 任务协作平台。仓库当时仅有 1 次初始提交，`app/` 仍是 create-next-app 模板，架构定义全部沉淀在 `docs/` 的 11 份规划文档中。

**关键判断**：文档描述的是**目标架构**而非已实现代码，因此在架构文档中显式区分 as-is / to-be，避免把设计误记为现状。

**产出**：
- `docs/architecture.md` — 系统架构设计文档 v1.0。含现状对照、五层架构（L0 客户端 → L1 表现层 app/ → L2 组件层 components/ → L3 应用服务层 actions/+api/ → L4 领域层 lib/ → L5 PostgreSQL）、核心模块职责清单、四种交互通道（RSC 读 / Server Action 写 / Route Handler / URL Params）、四条关键数据流（认证与 Workspace、Issue CRUD、看板拖拽乐观更新、AI 拆分到批量落库）、数据模型、安全与部署设计、演进路线。
- `docs/architecture-diagram.html` — 自包含图形化架构图，四组 SVG：分层架构总览、核心组件依赖关系（正交布线）、关键业务数据流（AI 链路 + 拖拽链路）、部署拓扑。浅色主题，无外部依赖。

**技术约定沉淀**：
- 五层依赖单向向下，禁止 `components/` 直连 `lib/prisma`、禁止 `lib/` 反向引用 React。
- Server Action 固定四步：校验（Zod）→ 鉴权（Session）→ 授权（Workspace 归属）→ 写库 + `revalidatePath`。
- 统一返回契约 `ActionResult<T>`，AI 输出不合 Schema 时零写入，批量创建走 `$transaction` 保证全成功或全失败。
- 状态枚举固定 `BACKLOG / TODO / IN_PROGRESS / DONE`。

**备注**：`package.json` 的 name 为 `helio-app`，与产品名 TaskFlow 不一致，后续可统一。

## 交付：TaskFlow 用户界面设计方案 v2.0（代号「静默」）

**背景**：`docs/ui-mockups.md` v1.0 只是色彩清单 + 页面效果图说明，缺少令牌体系、信息架构、导航模型与无障碍规范。本次输出全新一套方案替代之。

**产出文件**
- `docs/ui-design-system-v2.md` — 完整设计规格（12 章：设计原则、用户与场景、令牌系统、信息架构与布局、六条核心流程、组件规范、导航与键盘地图、模块优先级、无障碍、交付验收、与 v1.0 差异、术语表）
- `docs/ui-design-system-v2.html` — 可视化规范页，自包含、无外部依赖、支持深浅主题切换、按钮与输入框含真实交互态

**方案关键决策（后续实现需遵守）**
1. **三层令牌架构**：Primitive → Semantic → Component。组件样式禁止直接引用 Primitive，换肤与密度切换只动语义层。
2. **主题机制改为 `[data-theme]` 属性驱动**，替代现有 `app/globals.css` 里的 `prefers-color-scheme`，以支持用户在设置页手动覆盖系统偏好。
3. **紫色独占品牌与交互**。v1.0 让紫色同时承担品牌色与「进行中」状态，看板上互相干扰。状态色改为：BACKLOG `#85858F` / TODO `#5B8DEF` / IN_PROGRESS `#D9A03C` / DONE `#3FA65C`（深色值）。
4. **深色层级用「边框 + 微投影」双通道**，不能沿用浅色阴影思路。
5. **字阶基准 14px**（工具型产品取密度），中文不得小于 12px，字重只用 400/500/600 避免伪粗体。
6. **五态强制**：idle/loading/empty/error/success 必须全部设计，对应 `architecture.md` §11。
7. **破坏性操作采用「执行 + 5 秒撤销」而非二次确认**。
8. **拖拽必须有键盘替代**（`⌘↑`/`⌘↓`），对齐 `@dnd-kit` 键盘传感器。
9. 适配策略：桌面 Web 优先（基准 1440×900），六档断点行为对照表，移动端降级为列表 + 长按选状态。

**已核验的对比度数值**：`--text-primary` 17.6:1、`--text-secondary` 7.3:1、`--text-tertiary` 3.6:1（仅限 ≥16px）、白字对 `--brand-500` 4.7:1、状态色文本均 ≥5.0:1。

**下一步**：评审通过后先落地 `app/globals.css` 的语义令牌段与 `components/ui/` 原子组件，再进入 Sprint 1 页面实现。实施前需按仓库根目录 `AGENTS.md` 提示阅读 `node_modules/next/dist/docs/`，并核对已安装 Tailwind v4 的 `@theme inline` 实际行为。

- `Dockerfile`（3 阶段）+ `docker/entrypoint.sh`（`prisma migrate deploy` 重试 30 次后启动）+ `docker-compose.yml`（app + postgres:16-alpine，healthcheck、named volume、`env_file: required: false`）+ `.dockerignore`
- `app/api/health/route.ts`：200 ok / 503 degraded（列出缺失变量名）
- `app/page.tsx` 改为 TaskFlow 落地页；`app/layout.tsx` 元数据与 `lang="zh-CN"`
- `.github/workflows/ci.yml`、`.prettierrc.json`、`.prettierignore`、`.env.example`、README 全面重写
- package.json 新增脚本：`format`、`format:check`、`db:generate/deploy/migrate/studio`

**关键决策与踩坑**
1. **Prisma 7 装不上**：`prisma@7.10.0` 的依赖链（`@prisma/composer` → `alchemy` → `@effect/vitest`）请求 `effect@^4.0.0-rc.113`，npm 报 ETARGET 不存在。**降级到 Prisma 6.19.3**（CLI + client 同版本），稳定且与 ADR 的 `prisma-client-js` 生成器一致。
2. **`.gitignore` 原有 `.env*` 会把 `.env.example` 一起忽略**，已改为 `.env` / `.env.*` + `!.env.example`，并用 `git check-ignore -q` 实测确认。
3. **`.dockerignore` 是必需项**：缺它时 `COPY . .` 会用宿主机的 Windows `node_modules` 覆盖镜像内 Linux 依赖，且会把 `.env` 打进镜像。
4. **ESLint 分层护栏落地**：`no-restricted-imports` 把 `architecture.md` §4 的依赖方向铁律变成 lint error，并用反向用例实测两条规则均能拦截。
5. `next build` 在沙箱内会因 `.next` 批量删除超过 50 文件被 safe-delete 保护拦截，需以非沙箱方式运行。
6. Next 16 要点：Turbopack 默认（scripts 无需 `--turbopack`）、`next lint` 已移除（直接用 ESLint CLI）、`cookies()/headers()/params/searchParams` 全部为异步、`middleware` 更名 `proxy`（本项目路由保护放在 `(dashboard)/layout.tsx`，暂不需要 proxy）。

**已验证**：`npm run lint` ✅、`npm run format:check` ✅、`npx prisma validate` ✅、`npx prisma generate` ✅、`npm run build` ✅（4 条路由，`/api/health` 为 dynamic）。
**未验证**：本机 Docker 守护进程未运行，`docker compose up -d --build`、容器内迁移、健康检查状态均未实测，需启动 Docker Desktop 后补验。

**下一步**：第 1 梯队 —— `lib/auth.ts`、`lib/permissions.ts`、`lib/errors.ts`、`actions/auth.ts`、`actions/workspace.ts`、`app/(auth)/login`、`app/(dashboard)/layout.tsx` 路由保护，并引入 Jest + Playwright。

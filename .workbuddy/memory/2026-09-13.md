**核心缺陷（P0）**：`DocumentEditor.tsx:19-23` 自动保存无限循环 —— `dirty` 永不复位，每次保存完成 `pending` true→false 都会重新排一次 `requestSubmit()`，形成「每 ~1.2s 写一次库、每次 +1 contentVersion 并插一条 DocumentVersion」的持续性写入；UI 文案显示「已保存」掩盖了循环；第二标签页会退化为 CONFLICT 请求风暴。同时 `setDirty(true)` 在已 true 时是 no-op → 不重渲染 → effect 不重跑 → 定时器不重置，防抖实际退化为「首次击键后 1.2s 保存」，与文案「停止输入后自动保存」不符。

**其它缺陷**
- P1：action 层「按文档所属工作区鉴权、按上下文工作区写入」（`assertDocumentAccess` 返回值被丢弃）；`proxy.ts` matcher 未含 `/documents`；`DOCUMENT_CONTENT_MAX_LENGTH=200_000` 与 Server Action 默认 1MB 传输上限不对齐（CJK 场景 Zod 报错永远不触发）
